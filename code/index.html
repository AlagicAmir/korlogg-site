Redeem a code in Körlogg

Did you get a code for Körlogg, for example from your accountant? This is how you activate Körlogg Pro with it.

iPhone

  1. Install Körlogg from the App Store.

  2. Tap the link you got, or scan the QR code with the camera. The App Store opens and shows the offer. Or open Körlogg, go to Settings → Redeem code and type the code.
  3. Tap Redeem and confirm. Körlogg Pro is now active.

Android

  1. Open Google Play, tap your profile icon and choose Payments & subscriptions → Redeem code. Or simply open the link you got.
  2. Type the code and confirm.
  3. Open Körlogg. Pro is now active.

What happens afterwards

A code for a free period on the yearly subscription: after the free period the subscription renews at the price shown in the App Store or Google Play unless you cancel. You can cancel any time in your App Store or Google Play subscriptions.

A lifetime code never renews and never costs anything later.

Questions, or a code that does not work? Email support@korlogg.com or see Support.
