Een code inwisselen in Körlogg

Heb je een code voor Körlogg gekregen, bijvoorbeeld van je boekhouder? Zo zet je er Körlogg Pro mee aan.

iPhone

  1. Installeer Körlogg uit de App Store.

  2. Tik op de link die je hebt gekregen, of scan de QR-code met de camera. De App Store opent en toont de aanbieding. Of open Körlogg, ga naar Instellingen → Code inwisselen en typ de code.
  3. Tik op de knop om in te wisselen en bevestig. Körlogg Pro is nu actief.

Android

  1. Open Google Play, tik op je profielfoto en kies Betalingen en abonnementen → Code inwisselen. Of open gewoon de link die je hebt gekregen.
  2. Typ de code en bevestig.
  3. Open Körlogg. Pro is nu actief.

Wat gebeurt er daarna?

Een code voor een kosteloze periode op het jaarabonnement: na die periode wordt het abonnement verlengd tegen de prijs die in de App Store of Google Play staat, tenzij je opzegt. Je kunt op elk moment opzeggen bij je abonnementen in de App Store of Google Play.

Een levenslange code wordt nooit verlengd en kost later nooit iets.

Vragen, of werkt de code niet? Mail naar support@korlogg.com of kijk bij Support.
