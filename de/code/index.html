Code in Körlogg einlösen

Sie haben einen Code für Körlogg erhalten, zum Beispiel von Ihrer Steuerberatung? So schalten Sie damit Körlogg Pro frei.

iPhone

  1. Installieren Sie Körlogg aus dem App Store.

  2. Tippen Sie auf den Link, den Sie erhalten haben, oder scannen Sie den QR-Code mit der Kamera. Der App Store zeigt Ihnen das Angebot. Oder öffnen Sie Körlogg, gehen Sie zu Einstellungen → Code einlösen und geben Sie den Code ein.
  3. Tippen Sie auf Einlösen und bestätigen Sie. Damit ist Körlogg Pro freigeschaltet.

Android

  1. Öffnen Sie Google Play, tippen Sie auf Ihr Profilbild und wählen Sie Zahlungen und Abos → Code einlösen. Oder öffnen Sie einfach den Link, den Sie erhalten haben.
  2. Geben Sie den Code ein und bestätigen Sie.
  3. Öffnen Sie Körlogg. Pro ist jetzt freigeschaltet.

Was danach passiert

Ein Code für einen kostenlosen Zeitraum im Jahresabo: Danach verlängert sich das Abo zu dem Preis, der im App Store bzw. bei Google Play angezeigt wird, sofern Sie nicht kündigen. Sie können jederzeit in Ihren Abos im App Store oder bei Google Play kündigen.

Ein lebenslanger Code verlängert sich nie und kostet später nichts.

Fragen, oder der Code funktioniert nicht? Schreiben Sie an support@korlogg.com oder sehen Sie unter Support nach.
